# Codex-адаптер

1. До любых действий с репозиторием или GitHub полностью прочитай каноническую процедуру [`.claude/skills/merge-shepherd/SKILL.md`](../../../.claude/skills/merge-shepherd/SKILL.md).
2. Следуй ей с обычным приоритетом инструкций Codex: слово `headless` не отменяет системные ограничения, безопасность или необходимость сообщить настоящий блокер.
3. До записи в GitHub проверь `gh auth status` и `gh api user --jq .login`. Запись разрешена только от `ivanarama`; иначе остановись без изменений.
4. Считай `$merge-shepherd` Codex-эквивалентом `/merge-shepherd`. Упоминания соседних этапов описывают маршрут и не разрешают запускать их автоматически.
5. Перед каждым изменением перечитывай состояние PR; локальный main не изменяй.
6. На Windows используй PowerShell-эквиваленты команд, сохраняя семантику и проверяя коды возврата. Перед обязательными проверками убедись, что доступны `onebase`, `git` и `gh`.
7. Сохраняй полномочия, лимиты, маркеры `pp:*`, GitHub-метки и точный формат `ИТОГ:` из канонической процедуры.

Логика конвейера живёт только в канонической процедуре; этот файл — слой совместимости Codex.
