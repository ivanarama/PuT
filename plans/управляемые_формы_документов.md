# План: Управляемые формы документов с табличными частями

## Контекст

Форма для РеализацияТоваров уже создана (`forms/реализациятоваров/`). Нужно создать формы для остальных 8 документов с ТЧ. Документы делятся на 4 группы по структуре — формы внутри группы похожи, отличаются только парой полей.

Уже готовая форма-референс: `forms/реализациятоваров/формаобъекта.form.yaml` + `.form.os`

| # | Документ | Контрагент | Особенности | Директория |
|---|----------|------------|-------------|------------|
| A1 | ПоступлениеТоваров | Поставщик | — | forms/поступлениетоваров/ |
| A2 | ВозвратОтПокупателя | Покупатель | Основание (ref:Реализация) | forms/возвратотпокупателя/ |
| A3 | ВозвратПоставщику | Поставщик | Основание (ref:Поступление) | forms/возвратпоставщику/ |

Общие признаки: Организация, Склад(и), Причина, Сумма. ТЧ без НДС: Номенклатура, Количество, Себестоимость.

## Макеты форм

### Группа A: Торговля с НДС

**Вкладка 1 — Основное:**
- Номер (readonly)
- Дата (required)
- Организация (choice)
- [для Возвратов] Основание (choice, readonly — заполняется из документа-основания)
- Итоги: СуммаБезНДС, СуммаНДС, Сумма (readonly)

**Вкладка 2 — Контрагент и склад:**
- Покупатель или Поставщик (required, choice)
- Склад (required, choice)
- [для Счёта и Реализации] ТипЦенПродажи (choice)
- СпособУчетаНДС (choice)
- [для Счёта] СрокОплаты, Комментарий

**Вкладка 3 — Товары:**
- Табличная часть (6 колонок)
- Кнопки: «Пересчитать», «Очистить»

**Обработчики .form.os:**
- ПриОткрытии: defaults (Дата, СпособУчетаНДС = ВТомЧисле)
- ПередЗаписью: validate (контрагент, склад, ТЧ ≠ 0) + ПересчитатьИтоги()
- КонтрагентПриИзменении: auto-fill ТипЦенПродажи из контрагента (для A1, A4)
- СпособУчетаНДСПриИзменении: recalculate
- ПересчитатьИтоги(): Сумма = Кол*Цена, СуммаНДС через СуммаНДСстроки(), итого в шапку
- КнопкаПересчитать / КнопкаОчистить

### Группа B: Складские операции

**Одна вкладка — всё на одной странице** (документы простые):

Шапка:
- Номер (readonly), Дата (required), Организация (choice)
- [B1] Склад, Причина
- [B2] СкладОтправитель, СкладПолучатель
- Сумма (readonly)

ТЧ:
- Номенклатура, Количество, Себестоимость
- Кнопки: «Пересчитать», «Очистить»

**Обработчики .form.os:**
- ПриОткрытии: default даты
- ПередЗаписью: validate (склад, ТЧ ≠ 0) + recalculate
- ПересчитатьИтоги(): Сумма = Σ(Кол * Себестоимость)

### Группа C: Оприходование

Аналогично B, но ТЧ с Ценой вместо Себестоимости:

Шапка: Номер, Дата, Организация, Склад, Причина, Сумма (readonly)
ТЧ: Номенклатура, Количество, Цена, Сумма

**Обработчики:** те же, Сумма = Σ(Кол * Цена)

### Группа D: Установка цен

Самый простой документ:

Шапка: Номер, Дата, Организация, ТипЦен (required, choice)
ТЧ Цены: Номенклатура, Цена

**Обработчики:**
- ПриОткрытии: default даты
- ПередЗаписью: validate (ТипЦен, ТЧ ≠ 0)

## Проверка

- Открыть каждый документ в UI, проверить что форма рендерится
- Заполнить ТЧ, нажать «Пересчитать» — итоги должны пересчитаться
- Сохранить без обязательных полей — должна быть ошибка валидации
- Проверить автозаполнение: ТипЦенПродажи из контрагента, СпособУчетаНДС по умолчанию
- Переключить язык — заголовки вкладок и полей на месте
