# План: Документы Сборка и Разборка товаров

## Контекст

Для учёта производственных операций (комплектация, сборка мебели из деталей, разборка на комплектующие) нужны два документа:

- **Сборка товаров** — списывает комплектующие (ФИФО), оприходует готовое изделие (новая партия)
- **Разборка товаров** — списывает готовое изделие (ФИФО), оприходует комплектующие (новые партии)

Оба документа имеют одинаковую структуру (2 ТЧ), различаются семантикой:
- Сборка: Расход = компоненты, Приход = продукция
- Разборка: Расход = продукция, Приход = компоненты

---

## Регистры

Используются **существующие** регистры — новые не нужны:

| Регистр | Сборка | Разборка |
|---------|--------|----------|
| ОстаткиТоваров | Расход (компоненты) + Приход (продукция) | Расход (продукция) + Приход (компоненты) |
| ПартииТоваров | Расход из ФИФО-партий + Приход (новая партия) | Расход из ФИФО-партий + Приход (новые партии) |

Взаиморасчеты и ВаловаяПрибыль — **не затрагиваются** (нет контрагента).

## Логика проведения

### Сборка товаров

1. Собрать потребность из ТЧ Расход (сводная карта по Номенклатура)
2. ФИФО-запрос к ПартииТоваров.Остатки (тот же шаблон, что в списаниетоваров.posting.os)
3. Проверить достаточность остатков
4. На каждую строку ТЧ Расход:
   - **ПартииТоваров.Расход** — из ФИФО-партий (ДатаПоставки, Сумма)
   - **ОстаткиТоваров.Расход** — по ФИФО-себестоимости
5. Итого_Расхода = Σ(себестоимость всех списанных компонентов)
6. На каждую строку ТЧ Приход:
   - **ПартииТоваров.Приход** — новая партия (ДатаПоставки = this.Дата), себестоимость распределяется пропорционально количеству
   - **ОстаткиТоваров.Приход** — по распределённой себестоимости
7. Распределение себестоимости: `СтоимостьСтроки = Итого_Расхода × (КолСтроки / КоличествоВсегоПриход)`

### Разборка товаров

1. Собрать потребность из ТЧ Расход (готовая продукция)
2. ФИФО-запрос к ПартииТоваров.Остатки
3. Проверить достаточность
4. На каждую строку ТЧ Расход:
   - **ПартииТоваров.Расход** — ФИФО
   - **ОстаткиТоваров.Расход** — ФИФО-себестоимость
5. Итого_Расхода = Σ(себестоимость списанной продукции)
6. На каждую строку ТЧ Приход:
   - **ПартииТоваров.Приход** — новая партия (ДатаПоставки = this.Дата)
   - **ОстаткиТоваров.Приход** — себестоимость распределяется пропорционально
7. `СтоимостьСтроки = Итого_Расхода × (КолСтроки / КоличествоВсегоПриход)`

## Управляемые формы

### Макет (одинаковый для обоих документов)

**Вкладка 1 — Основное:**
- Номер (readonly), Дата (required)
- Организация (choice), Склад (required, choice)
- Комментарий
- Сумма операции (readonly)

**Вкладка 2 — Расход:**
- ТабличнаяЧасть Расход (Номенклатура, Количество, Себестоимость)
- Надпись-подсказка: «Списываемые позиции» (для Сборки — «Комплектующие», для Разборки — «Разбираемая продукция»)

**Вкладка 3 — Приход:**
- ТабличнаяЧасть Приход (Номенклатура, Количество, Себестоимость)
- Надпись-подсказка: «Оприходуемые позиции» (для Сборки — «Готовая продукция», для Разборки — «Комплектующие»)

**Обработчики .form.os:**
- ПриОткрытии: default даты
- ПередЗаписью: валидация (Склад, обе ТЧ не пустые, Расход ≠ Приход по одинаковым номенклатурам — предупреждение)
- КнопкаОчиститьРасход / КнопкаОчиститьПриход

## Проверка

- Создать Сборку: списать 4 ножки + 1 сиденье → оприходовать 1 табурет
- Провести — проверить ПартииТоваров (компоненты списаны ФИФО, табурет оприходован новой партией)
- Создать Разборку: разобрать 1 табурет → оприходовать 4 ножки + 1 сиденье
- Провести — проверить регистры (обратная операция)
- Проверить себестоимость: стоимость табурета ≈ сумма стоимостей компонентов
- Проверить управляемые формы: вкладки, валидация, очистка ТЧ
