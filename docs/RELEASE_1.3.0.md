# PuT 1.3.0

- Восстановлено меню по рабочим задачам из экспериментальной раскладки 3 октября. Главная и пять разделов используют группы и вложенные папки; состав команд учитывает текущие роли.
- Цветные карточки клиента и товара показывают задолженность, неоплаченные документы, нераспределённые оплаты, заказы, остатки, резервы и актуальные цены. Из клиента можно открыть новый заказ или счёт с заполненным покупателем.
- Отборы виджетов сворачиваются, ссылочные колонки заполнены, строки открывают карточки. Показатели обновляются после изменения данных.
- Добавлены контроль этапов заказов, зависимый выбор спецификации сборки и очередь длительных операций с сохранением номера задания и просмотром результата.
- Подготовлено встроенное руководство с девятью иллюстрациями и воспроизводимой съёмкой через `onebase docs capture`.
- Ночное демо заполняется относительно текущей даты после восстановления архива. Добавлены независимые проверки продаж и выручки месяца.
- Минимальная платформа — OneBase **0.13.0**. Проверенная поставка — **0.13.0+put.1.ac6231b8**; точная зависимость и SHA256 патча записаны в `platform-patches/runtime.json`, проверяются перед развёртыванием и используются в CI.

Обновление требует миграции базы. Перед применением сохраните PostgreSQL dump, предыдущий бинарь и настройки службы. Полный сброс документов допустим только для демонстрационной базы; обычную рабочую базу обновляйте без `reset_demo.py`.
