# PuT 1.3.3

- Исправлен переход «Где застряло» из заказов: кириллица в URL больше не приводит к пустому отчёту. Кнопка «Назад» возвращает в исходный документ.
- Добавлены 14 демонстрационных заказов: по одному заказу покупателя и поставщику для каждого из семи этапов. Новый заказ сохранён как черновик; активные заказы проведены. Завершённые заказы имеют фактическую отгрузку или приёмку, отменённые — документы снятия обеспечения. История записывается обычными переходами этапов.
- Заполнение дополняет существующую демобазу без очистки и повторного создания примеров. Ночной сброс проверяет наличие всех семи этапов у обоих видов заказов.

Проверенная сборка — **0.13.0+put.3.ac6231b8**, минимальная версия платформы — **0.13.0**. Обновление существующей демобазы выполняется без параметра «Очистить».
