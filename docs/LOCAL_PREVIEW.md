# Локальный стенд PuT

Для первого запуска на Windows соберите исполняемый файл по [инструкции для поддерживаемой версии OneBase](../platform-patches/README.md#сборка-для-windows). Затем откройте PowerShell в любой папке внутри клона PuT.

```powershell
$projectDir = (git rev-parse --show-toplevel)
& (Join-Path $projectDir 'scripts/start_preview.ps1')
```

Скрипт откроет [локальный стенд](http://127.0.0.1:8100/ui/). При первом запуске он создаёт SQLite `.local/preview.db`, заполняет её демонстрационными данными и добавляет администратора `preview`. Его сгенерированный пароль хранится в `.local/credentials.txt`. При следующих запусках используется существующая база. Сервер слушает адрес `127.0.0.1`, журналы находятся в `.local/server.log` и `.local/server-error.log`. Чтобы выбрать другой порт или запустить стенд без открытия браузера, передайте скрипту `-Port 8101` или `-NoBrowser`.

В интерфейсе есть [иллюстрированное руководство](http://127.0.0.1:8100/ui/help). Для подготовки демонстрации пригодятся инструкции по [обновлению снимков и экспорту справки](HELP_SCREENSHOTS.md) и [сбросу демобазы](DEMO_RESET.md).

## Что посмотреть в демобазе

1. Главная: показатели месяца, рейтинги и ожидаемые поставки. Нажмите строку таблицы для открытия карточки. «Отборы» раскрываются по нажатию. Изменения документов обновляют связанные виджеты.
2. Контрагент: долг, просрочка, кредитный лимит, неоплаченные документы, заказы и история. «Ввести на основании» открывает несохранённый заказ или счёт с заполненным клиентом.
3. Номенклатура: остатки по складам, резерв, свободное количество, товары в пути, текущие цены и движения. Цветные области разделяют сведения; таблицы сводок нельзя редактировать.
4. Заказ покупателя/поставщику: строгие этапы обработки и история. Завершение и отмена проверяют незакрытое обеспечение.
5. Сборка товаров: выберите готовое изделие — список спецификаций ограничится этим изделием. Кнопка заполнения заменяет состав документа выбранной спецификацией.
6. В импорте номенклатуры, выгрузке БП3 и закрытии месяца запустите обработку в фоне и обновите статус. Номер задания можно вставить после повторного открытия формы. Пока задача активна, повторный запуск той же обработки с теми же параметрами возвращает её номер. При других параметрах оператор увидит сообщение о занятой обработке и сможет повторить запуск после завершения задачи.
7. Панель руководителя: `/ui/page/Панель`. Показывает показатели месяца и открытые заказы со ссылками. Меню остальных ролей ограничено их ежедневными задачами; административные права остаются у администратора.

## Проверки конфигурации

Команды используют отдельную SQLite для тестов проведения. Для каждого прогона создаётся новый файл.

```powershell
$projectDir = (git rev-parse --show-toplevel)
$binary = Join-Path $projectDir '.local/onebase-preview.exe'
$testDb = Join-Path $projectDir ('.local/verification-' + [Guid]::NewGuid().ToString('N') + '.db')
& $binary --no-gui check --project $projectDir
& $binary --no-gui lint --project $projectDir
go -C $projectDir test ./...
python -X utf8 (Join-Path $projectDir 'scripts/test_demo_reset.py') --onebase $binary
& $binary --no-gui migrate --project $projectDir --sqlite $testDb
& $binary --no-gui procrun --project $projectDir --sqlite $testDb --proc ЗаполнитьТестовуюБазу
& $binary --no-gui test --project $projectDir --sqlite $testDb
```

В CI сценарий [scenario_tests.sh](../scripts/scenario_tests.sh) дополнительно проверяет суммы движений и загрузку УПД из XML на двух временных базах.
