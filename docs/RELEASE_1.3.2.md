# PuT 1.3.2

- Общие скрипты интерфейса получают URL с хэшем содержимого. Браузер может использовать их из кэша без проверки на каждом переходе; после изменения скрипта его URL меняется автоматически. Прямые ссылки без версии и устаревшие хэши сохраняют обязательную ревалидацию.
- Публичные JS, CSS и SVG сжимаются gzip на стороне OneBase для клиентов, поддерживающих gzip. Сжатие не распространяется на формы, API и SSE; ответы 304 и запросы диапазонов сохраняют прежний контракт.
- Регрессионные проверки раздачи ресурсов добавлены в поставляемый патч платформы и CI конфигурации.

Требуется проверенная сборка **0.13.0+put.2.ac6231b8**. Минимальная версия платформы — **0.13.0**. Обновление применяется без перезаполнения данных.
