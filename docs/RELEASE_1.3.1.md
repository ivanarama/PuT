# PuT 1.3.1

- В списке номенклатуры скрыта техническая колонка «Идентификатор 1С».
- Контекстная справка подключена ко всем 21 виду документов. Добавлены главы о продажах, закупках, возвратах, складских операциях, кассе, банке и расчётах; дополнены инструкции по установке цен и закрытию заказов.
- Инструкция по приходному кассовому ордеру содержит снимок настоящего интерфейса. В руководстве теперь восемь глав и десять иллюстраций.

Требования к платформе сохранены: OneBase **≥ 0.13.0**, проверенная сборка **0.13.0+put.1.ac6231b8**. Обновление применяется к существующей базе без перезаполнения демонстрационных данных.
